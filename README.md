# Field Survey App v4.3.9

以 GitHub Pages 發布的單頁現勘 PWA。解壓縮後將本資料夾內的 `index.html`、`manifest.webmanifest`、`sw.js` 與 `icons/` 上傳至 repository 根目錄。

## 原始影像保留

從 **案件資料 → 影像保存模式** 可以開關「保留原始影像（新照片）」，預設為開啟。

- **匯入／使用手機原生相機**：保留瀏覽器 File API 所提供的原始影像位元組（例如 JPG／HEIC）。不自動改寫來源檔或 EXIF。
- **網頁內建即時相機**：若支援 `ImageCapture.takePhoto()`，保留相機拍出的來源 JPEG/Blob；否則另外保存完整取景串流畫格，**此備援檔不是手機原始相機照片**。照片編輯畫面會標示來源類型。
- 為了維持地圖、報表操作效率，系統繼續產生壓縮 JPG 作為預覽／報表影像。來源檔另外保存在同一裝置、同一網站來源的 IndexedDB `originals` 物件儲存區。
- **既有 v4.3.7 或更舊版本的壓縮照片無法還原出原始影像**；只有啟用本功能後新匯入或新拍攝的照片才會擁有對應來源檔。

## 如何備份與取回

- 單張照片：開啟照片編輯 → **取出原始／來源檔**，保留原副檔名；也可以另行下載報表用 JPG。
- 完整備份：**全部照片 ZIP（含原檔）**。內含 `photos/`、`originals/`、`photo_metadata.csv` 與 `project_data.json`。
- 還原備份：**載入專案** → 選擇本 App 產生的 ZIP；會將專案資料與原始檔一起恢復。
- 單獨的 **JSON 備份不包含大型二進位原檔**，不可取代 ZIP 完整備份。
- ZIP 檔目前有行動裝置記憶體安全限制：總照片約 180 MiB 以上時會提示改以單張下載／分批備份，避免大型檔案導致行動裝置瀏覽器當機。

## 重要限制

原始影像目前仍僅保存在手機瀏覽器／主畫面 PWA 的網站資料裡，**不會自動進相簿、GitHub 或雲端，也不是永久可靠備份**。清除網站資料、刪除 App 或裝置儲存空間不足時可能遺失。正式工程現勘請在每天作業結束後將 ZIP 匯出並保存到受控、安全的備份位置。iPhone、Samsung／Android 實機拍照與大批量備份需另外現場驗證。
