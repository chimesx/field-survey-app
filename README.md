# Field Survey App v4.4.1

## 更新說明

- 以 v4.4 為基底，保留現有資料結構、原始／來源影像保留、時間軸、地圖、圖徵、語音、Checklist 與 ZIP/JSON 專案備份等功能。
- **手機照片編輯**：預設先顯示點位編號、類型、狀態、備註和語音輸入；GPS、EXIF、拍攝方向、原檔與照片操作改為「進階資料」收合區。儲存鍵固定於底部，另提供「儲存並下一張」。
- **電腦編輯**：新增「現勘紀錄／定位與方位／照片與原檔」三個分頁。
- **相機快門**：快速模式在按鍵當下擷取影片畫格，不再先等新的 GPS 定位；持續使用定位監看已得到的有效座標。高畫質優先模式則在瀏覽器支援時使用 ImageCapture（可有額外延遲）。影像處理、原始來源保存及寫入本機資料庫會在擷取後進行；系統會顯示拍攝和儲存狀態。這不等於原生相機零快門延遲。
- **iOS 主畫面 App PDF**：報告預覽頁改用「產生 PDF → 儲存 PDF／分享 PDF」，不再依賴主畫面模式不一定有效的 `window.print()`。Safari 和電腦仍保留傳統列印備援。

## PDF 技術說明

- PDF 由瀏覽器本機產生，不會把照片傳到遠端轉檔伺服器；版面由 html2canvas 逐頁截圖，再寫入 A4 PDF 容器。
- **PDF 是點陣化的影像式報告，內文字不可搜尋／選取**。優點是不需要額外繁體中文字型；大量照片時輸出可能較慢、檔案較大，請先做現場驗收。
- 地圖截圖、照片和版面仍依賴 html2canvas 及其能否取得影像。第一次開啟需有網路載入前端函式庫，之後離線可用性依瀏覽器快取狀況。
- iPhone PWA 分享／儲存功能仍受 iOS Web Share API、檔案大小與記憶體限制，務必以 iPhone 實機測試 5、20、50 張照片的情境。

```

```

發布後重新整理 Safari／主畫面 App；Service Worker cache version 已更新到 `field-app-v4.4.1`。**不要先清除 iPhone 網站資料或刪除 App**，以免本機 IndexedDB 照片遺失；升級前先使用照片 ZIP（含原檔）與專案 JSON 雙備份。
