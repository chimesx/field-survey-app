# Field Survey App v4.4.4 — Field Usability Fix

可直接部署至 GitHub Pages 的靜態網站。延續 v4.4.3 的現勘資料、照片、錄音、繪圖、時間軸、報告與 PDF 功能。

## v4.4.4 更新內容

### 1. GPS 快門定位時效與品質

- 內建網頁相機拍照時，**優先使用快門前最新的 GPS**。僅接納距離快門不超過 5 秒的定位記錄；不再拿最多 60 秒前的高精度座標充當拍攝位置。
- 有定位但精度超過 ±10 公尺、或資料距快門超過 3 秒時保留座標並標記「GPS 需確認」。沒有足夠新的定位則保存照片為「待定位」。
- 編輯頁「定位／方位」進階區提供品質狀態；照片清單也標示「GPS 需確認」。
- 手動拖曳照片 Marker 或指定地圖位置後，保留原始座標快照與人工修正資訊，便於後續追溯。
- 使用手機原生相機但照片沒有 GPS EXIF 時，返回系統後取得的座標僅作待確認參考；不能當作拍照當下位置。不可用時不取用任意舊定位。
- **限制**：手機 GPS 在鋼構、室內、大型廠房附近仍可能偏移。本功能改善資料選擇策略，不能取代現地實測或高精度測量。

### 2. 照片放大檢視

- 開啟照片編輯後，點上方縮圖、或在「照片／原檔」點「放大檢視」。
- 手機可雙指放大、拖曳、雙擊切換倍率；桌機可使用滑鼠滾輪及 ＋／－，最大 8 倍。
- 有保留來源檔時優先使用來源影像，無法解碼（例如部分 HEIC）時回退至系統 JPEG。
- 檢視器只讀取影像，不會更動原始檔或照片位置。

### 3. 介面字級與比例

- 手機：☰「更多」→「字體與顯示大小」；桌機：案件資料 → 介面顯示大小。
- 可選標準／大字／特大，調整主要文字、輸入欄及按鈕。
- 選擇存於該裝置 `localStorage`，不寫入專案 JSON；手機首次使用預設「大字」，桌機預設「標準」。
- 移除 `user-scalable=no` 的限制，改善系統可及性。
- 不影響正式 PDF 排版和文字大小設定。

## GitHub Pages 更新

將 ZIP 解壓後，把以下檔案與資料夾上傳至 `field-survey-app` repository 根目錄，覆蓋同名檔案並 Commit：

```
index.html
manifest.webmanifest
sw.js
icons/
```

建議先從舊版 App「匯出專案 JSON」與「匯出全部照片 ZIP（含來源影像）」備份。**不要為了更新而清空 iPhone Safari 網站資料或 IndexedDB**。

## 驗收建議

1. 在有 GPS 訊號的位置，確認現場相機 HUD 顯示最新精度；遮蔽訊號後拍照，檢查是否改成待定位／GPS 需確認。
2. 同一張照片在手機測雙指縮放、拖曳、還原；桌機測滑鼠滾輪。
3. 切換「標準、大字、特大」，測 iPhone 直式／橫式與 Android 的工具列是否仍可正常操作。
4. 確認原有照片、錄音、繪圖、時間軸和 PDF 報告仍在。

## 已進行檢查與限制

- JavaScript 與 Service Worker 語法檢查；Manifest JSON 驗證。
- GPS 新舊定位選擇、定位品質提醒與人工更正的單元測試。
- 隔離瀏覽器 DOM 模擬測試照片檢視器，以及手機直式／橫式／桌機的介面大小設定。
- **尚未在實際 iPhone／Samsung 手機驗證**相機定位、雙指操作、IndexedDB 長期保存與離線狀態；建議先做小批量現勘測試。
