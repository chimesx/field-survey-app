📷 影像保存模式
原始檔保存在此裝置網站的 IndexedDB。既有壓縮照片無法還原為原始檔。
⚠ 原始檔可能佔用大量手機空間。請定期使用「全部照片 ZIP（含原檔）」備份；單獨 JSON 備份不包含二進位原始檔。
📲 手機相簿保存
系統無法在 iPhone／Android PWA 中靜默寫入相簿。拍照後可從相機或照片編輯頁點「分享／存入相簿」，由使用者在系統介面確認保存。

📐 點／線／面圖徵管理

點「定位」可跳到該圖徵；按「刪除」只移除該筆，不會清除其他圖徵。也可以直接點地圖上的圖徵，從彈出資訊刪除。

⬇ 指定區域離線底圖

NLSC OpenData 臺灣通用電子地圖（不含等高線）
下載方式：① 先把主地圖移到場址並調整到要保存的範圍；② 從「更多 → 離線底圖」開啟本視窗；③ 選 Zoom 後按「下載目前視窗」。下載完成後，切到「NLSC OpenData（離線可用）」即可在已下載範圍離線瀏覽。OpenData 原生最高 Zoom 15。
OpenStreetMap 標準圖磚僅提供線上互動瀏覽，不會納入「離線區域下載」，以符合 OSM Tile Usage Policy。
